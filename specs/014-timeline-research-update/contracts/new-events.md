# Contract: New and changed timeline events

This is the per-event content contract for `input/timeline.md` and `editorial/events.yaml`. The **sources** column names the research row whose `Külső forrás` links are copied as they are (P = `events_patch.md`, U = `uhereczky_d18_kutatas.md` §9 table, U§6 = the report's section 6). The **image** column names the one cited page to crop. Hosts marked HUN need a browser ([research R5](../research.md#r5-getting-source-images)).

Titles are drafts for the owner's review. Event text follows [data-model.md](../data-model.md) and must keep each row's stated limits.
