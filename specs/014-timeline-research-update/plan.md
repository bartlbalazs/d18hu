# Implementation Plan: Timeline update from the October 2026 research

**Branch**: `master` (direct) | **Date**: 2026-10-11 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/014-timeline-research-update/spec.md`

## Summary

The work adds 34 new events and 5 changes to existing rows to the home page timeline, from the agreed research triage. It also makes three requested fixes: the Illés description wording, the 1903 map on the 1889 street-naming event, and the permit scan on the 1901 event.

This is a content change through the existing pipeline. Rows go into `input/timeline.md`, titles and image metadata into `editorial/events.yaml`, and source crops into `assets/events/forrasok/`. No parser, schema or component code changes.

Crops are made from each event's own cited pages. EPA and archive-portal PDFs are rendered locally. Hungaricana pages block scripts, so they are captured in a browser.

## Technical Context

**Language/Version**: TypeScript 6.0.3 on Node 22 (existing); content in Markdown and YAML

**Primary Dependencies**: Astro 7.3.3, sharp 0.35.4, remark (existing; none added). Poppler `pdftoppm` is used locally for one-off page rendering and is not a project dependency.

**Storage**: Files: `input/timeline.md`, `editorial/events.yaml`, `editorial/music.yaml`, `assets/events/`, `src/assets/archive/` + manifest

**Testing**: Vitest unit and site tests, html-validate, linkinator, Lighthouse CI (existing)

**Target Platform**: Static site on Firebase Hosting

**Project Type**: Static website (single project)

**Performance Goals**: Home page Lighthouse mobile ≥ 95/95/95/100; total initial weight ≤ 500 KB

**Constraints**: No runtime third-party requests; images self-hosted, responsive, lazy below the fold. Hungaricana returns 403 to scripted requests ([research R5](research.md#r5-getting-source-images)).

**Scale/Scope**: 142 → 175 events. Of the 34 new events, about 29 get one image crop each, plus 1 crop for M6 and 1 copied permit scan.
