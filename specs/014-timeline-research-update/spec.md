## Agreed triage

A row is **kept** when it tells a concrete story about the house, a named resident, or a moment in the street that a reader can picture, or when it closes a question the timeline currently leaves open. A row is **dropped** as filler when it only shows that a name appeared with the D18 address in a catalogue, with no story, date or detail a reader would remember. Several weak rows on one theme are **merged** into a single event.

Certainty uses the timeline's existing three levels. The label reflects the weakest link in what the row claims about the house or the person: **Igazolt** (contemporary document states it), **Valószínű** (strong but indirect, e.g. identity inferred from name and occupation), **Feltételezés** (a possibility built from incomplete or partly conflicting data).

### Edge Cases

- A new event shares a date with an existing one (e.g. 1924, 1947): both are shown and their order is stable.
- A merged event spans eras (e.g. N12 1930–1949, N21 1942–1950, N23 1945–1954): it is placed by its start date.
- Several events follow one person (Wágner: N27, N29, N16; Márkus: N31, N32, N18; Uhereczky: N5–N12, N34): each stands on its own and repeats the key identity caveat briefly.
- Names have variant spellings in the sources (Uhereczky/Uhareczky, Takáts/Takács, Földes Szerén/Szeréna, Róthmüller/Rothmüller): the text uses the main spelling and notes the variant where it matters.
- The word "timeline" also appears in four other songs' recording notes, shown in their sources panel. These are outside this request and are listed as a possible follow-up.
